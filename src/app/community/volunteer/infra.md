Infrastructure volunteers work on MathSoc's website and technical systems. The Lead, Infrastructure guides technical work and supports web developers, while the Vice-President, Communications helps connect website work to public-facing content and communication needs.

## Lead, Infrastructure

The Lead, Infrastructure is MathSoc's main technical infrastructure lead and primary developer for the MathSoc website. This role helps keep MathSoc's web systems maintainable, reliable, and easy for future volunteers to continue improving.

**Works with:** Website Committee, Vice-President, Communications, Business Manager, Board, and Council.

**What they do:** The Lead, Infrastructure coordinates the technical direction of the MathSoc website, reviews the feasibility of requested website features, supports website volunteers, monitors infrastructure during high-usage periods, and maintains clear documentation for future leads.

**Responsibilities**

- Determine the direction of the MathSoc website in coordination with the Website Committee.
- Review the feasibility of new requested website functionality.
- Monitor MathSoc infrastructure to help maintain uptime, especially during high-usage periods.
- Support volunteer web developers and content maintainers working on the website.
- Help the Vice-President, Communications make simple website content updates.
- Support Council and Board with infrastructure concerns.
- Maintain documentation and handoff notes for future Leads, Infrastructure.

**Good fit if you**

- Have web development experience or infrastructure experience.
- Care about maintainable code, documentation, and smooth handoffs.
- Can explain technical tradeoffs clearly to non-technical volunteers.
- Are comfortable coordinating with both developers and MathSoc leadership.

The Lead, Infrastructure is appointed and ratified by the Board of Directors for a one-year term. If you are interested in the role, email the VPC at [vpc@mathsoc.uwaterloo.ca](mailto:vpc@mathsoc.uwaterloo.ca). For questions about the appointment process, email the Chair at [chair@mathsoc.uwaterloo.ca](mailto:chair@mathsoc.uwaterloo.ca).

## Website Developer Volunteer

Website Developer Volunteers help build, maintain, and improve the MathSoc website.

**Works with:** Lead, Infrastructure and Vice-President, Communications.

**What they do:** The Lead, Infrastructure guides technical work and supports website volunteers. The Vice-President, Communications oversees public-facing communication and website content needs.

**Responsibilities**

- Help build and maintain website features.
- Fix bugs and improve reliability.
- Support content update workflows.
- Write documentation for future website volunteers.
- Collaborate on technical decisions with the Lead, Infrastructure.

**Good fit if you**

- Have some web development experience or are excited to learn.
- Can communicate clearly about your work.
- Care about accessible, student-friendly websites.
- Enjoy improving tools that lots of MathSoc members use.

If you are interested in website volunteering, email the current Lead, Infrastructure at [webdev@mathsoc.uwaterloo.ca](mailto:webdev@mathsoc.uwaterloo.ca).
