# Board games announcements

Edit public/board-games-preview/announcement.json:

- Set enabled to true to show the banner, or false to hide it.
- Set message to the announcement text.
- Change id for every new announcement, including a significant correction. Students who closed an older ID will see the new one.

Dismissal is remembered in that browser. If browser storage is unavailable, the banner still closes until the next page load. This file is public; include only student-facing information. Keep these instructions in docs, outside public.

The banner appears above the board-games hero, inside the preview beneath Biochar's main header. The catalogue development notice uses this banner. It is separate from the recurring Game Night section and the homepage announcements.
